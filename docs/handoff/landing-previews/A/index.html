What stop_reason indicates Claude wants to use a tool?

Domain 1 quiz, Agentic Architecture

Show the answer

C, tool_use. When Claude returns stop_reason: 'tool_use', it means the model wants to call one or more tools. Your code should execute the tools and return results.

What does tool_choice: 'auto' mean in the Anthropic API?

Domain 2 quiz, Tool Integration

Show the answer

C. tool_choice: 'auto' (the default) lets Claude decide whether to use a tool or respond directly based on the context of the conversation.

What is the purpose of a CLAUDE.md file in a project?

Domain 3 quiz, Claude Code

Show the answer

B. CLAUDE.md provides project-level instructions that Claude Code reads to understand conventions, architecture decisions, and how to work within a specific codebase.

What is chain-of-thought prompting?

Domain 4 quiz, Prompt Engineering

Show the answer

B. Chain-of-thought prompting asks Claude to show its reasoning process step by step, which improves accuracy on complex tasks by breaking them into smaller logical steps.

What is the purpose of context window management in long-running agent sessions?

Domain 5 quiz, Context Management

Show the answer

B. Long sessions accumulate tokens. Context management uses techniques like summarization, pruning tool results, and prioritizing recent context to stay within limits.
